# ЛПХ «Козьи деликатесы в Лисицыно»

Статический сайт семейного хозяйства с формой заказа. Заявки отправляются через Cloudflare Pages Function в Telegram.

## Что уже подготовлено

- Форма отправляет `POST /api/order`.
- Серверная функция находится в `functions/api/order.js`.
- Токен бота не хранится во frontend-коде.
- Добавлены серверная валидация, ограничение размера запроса, honeypot и базовое ограничение частоты заявок.

## Переменные окружения

На хостинге нужно создать две закрытые переменные:

- `BOT_TOKEN` — новый токен, полученный у `@BotFather`;
- `OWNER_CHAT_ID` — Telegram ID владельца, которому бот отправляет заявки.

Не записывайте реальные значения в `.env.example` и не добавляйте их в Git.

## Как получить OWNER_CHAT_ID

1. Владелец открывает созданного бота и нажимает **Start**.
2. Отправляет боту любое сообщение, например «Проверка».
3. Откройте в браузере адрес `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`.
4. Найдите в ответе объект `chat`, а внутри него поле `id`. Это и есть `OWNER_CHAT_ID`.
5. Не публикуйте адрес с токеном и закройте вкладку после копирования ID.

## Локальный просмотр

Обычный статический сервер показывает страницы, но не выполняет Cloudflare Function. Для полноценной локальной проверки потребуется среда Cloudflare Pages и локальные секреты в `.dev.vars`:

```text
BOT_TOKEN=новый_токен
OWNER_CHAT_ID=id_владельца
```

Файл `.dev.vars` уже исключён из Git. Не передавайте его другим людям.

## Публикация на Cloudflare Pages

1. Создайте проект Cloudflare Pages и загрузите этот сайт.
2. В настройках проекта откройте **Settings → Variables and Secrets**.
3. Добавьте `BOT_TOKEN` и `OWNER_CHAT_ID` как секреты.
4. Выполните повторное развёртывание сайта.
5. Откройте форму, отправьте тестовую заявку и проверьте сообщение от бота.

## Если заявка не приходит

- убедитесь, что владелец нажал **Start** в чате с ботом;
- проверьте правильность `OWNER_CHAT_ID`;
- убедитесь, что используется новый действующий токен;
- проверьте, что обе переменные добавлены в рабочее окружение Cloudflare;
- после изменения секретов повторно опубликуйте сайт.

Пользователь сайта увидит только понятное сообщение об ошибке; токен и технические ответы Telegram ему не показываются.
